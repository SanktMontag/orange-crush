# Team logos

Drop a logo here and it shows up on box scores: in each team's panel header and
at the start of its lane on the game timeline. Teams without a logo just show
their name.

- **File name:** the team name in lowercase with dashes (below), or the team's
  `team_id`, for example `2.png`. A name match wins over an id match.
- **Formats:** PNG (transparent background works best), WEBP, JPG or SVG.
- **Size:** anything square-ish; it's scaled down to fit. 128×128 or larger looks sharp.
- The Crush already uses `assets/logos/Crush_Round_Orange_30_Clean.png`; add
  `orange-crush.png` here only if you want to override it.
- New files appear the next time a box score is opened. No restart needed.
